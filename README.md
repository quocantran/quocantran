### 📌 Featured Architecture & Highlights

- 🎟️ **Distributed Movie Booking Microservices**:
  - Choreography-based **Saga Pattern** orchestrating cross-service distributed transactions across Booking, Seat, and Payment services.
  - **Transactional Outbox Pattern + Debezium CDC** eliminating dual-write hazards and ensuring zero data loss.
  - **Realtime Wallet & Seat Streaming** powered by Server-Sent Events (SSE) and Redis Pub/Sub.
  - **Ultra-Safe FinTech Payment Integration** with payOS featuring HMAC-SHA256 signature verification, anti-tamper, and idempotent atomic conditional state updates.
  - **Production-Grade Observability** with Prometheus metrics, Promtail log scrubbing (PCI-DSS/GDPR redaction), Loki log aggregation, and custom Grafana alerting dashboards.
